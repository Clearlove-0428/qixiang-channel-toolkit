# 文件范围

这个目录是可上传个人仓库的独立源码副本。原项目的工具、资料库和成果文件没有搬走，也没有覆盖。

## 纳入

- 原有资料管理、JSON 导入与合并、图像保存、页面采集、时间解析、候选分类、分析导出和网页界面。
- 从资料库生成逐帖浏览 HTML、JSONL、帖子表、媒体对应表和评论对应表的代码与空模板。
- 与上述功能对应的 Python / Node 测试，以及完全虚构的两帖示例。
- 安装、启动脚本、依赖清单、Node 锁文件、环境变量格式、Git 忽略规则与说明。

## 发行副本的调整

1. Playwright 使用标准包依赖，移除原电脑的 Codex 运行环境路径。
2. 模型权重和推理程序由环境变量指定，不再指向其他本地项目；没有模型时可以正常管理资料。
3. 浏览器登录配置默认放到当前资料目录，避免沿用原电脑的登录档案。
4. 首次启动生成新的采集连接令牌；仓库只保留占位格式示例，去重索引为空。
5. 启动器检查同端口的资料库路径，防止误打开另一份正在运行的资料库。
6. 逐帖导出接受显式数据库路径，兼容没有截图或模型表的新库，保留已有人工复核，不再把原项目的人工进度数字写死。
7. 浏览器界面测试使用临时资料库，移除访问原电脑 8765 服务和截取原项目数据的测试步骤。

## 排除

- 实际帖子及评论正文、SQLite 数据库、媒体、头像、快照、已生成的逐帖浏览数据。
- 问卷、访谈、成员姓名学号与资料文件名列表、研究报告和课堂演示稿。
- 本机连接令牌、登录配置、运行日志、虚拟环境、Node 依赖、模型和推理程序。
- 针对原项目材料清单的 `intake_materials.py` 与 `prepare_evidence.py`。
- 依赖原项目成果和其他聊天状态的 `finish_night_exports.py`、`night_display_guard.py` 及其测试。
- 历史进度、账号使用信息与原项目《项目接续.md》。

这些排除项包含资料、项目专项脚本和运行状态；不影响仓库中的资料管理、浏览器采集、复核与导出主流程。

## 使用边界

浏览器采集针对既有频道页面，保留按来源和可见范围记录的做法。帖子数、保存评论条数、模型候选数、人工分类数分别计量。页面评论数不等同于已保存评论文字条数，时间推算不等同于精确发布时间。

逐帖导出将媒体作为本地文件引用；它本身不会匿名化真实研究材料。发行包内的示例完全虚构。没有把原项目的全库 OCR、论文或演示文稿制作脚本包装为通用功能。
